# Scripts and Resources
### Contents

* ADAccountReport.ps1 - Traverse your Active Directory domain starting at a search base DN of your choice, and output a CSV file of user account information.
* Get-OktaGroupReport.ps1 - Export CSV of Okta groups, flag groups that might be used as exemption for MFA (using a keyword list).
* Invoke-OktaQuery.ps1 - Export CSV report of data from Okta, supply parameter corresponding to the type of report you need.
* Okta-event-types-reference.md - A reference for Okta events ingested to SIEM.
